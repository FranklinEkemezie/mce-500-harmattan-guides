# MCE 500 Level — Harmattan Study Guides

Compact, exam-oriented study guides for the 500-level Harmattan semester of Mechatronics Engineering at FUTO. Ten courses, one guide each. Every topic tells you **what to read** (chapter, section, page), **what to practise**, and **which past-paper question it unlocks** — so you stop reading textbooks cover to cover.

> These are student notes, not official course material. They are not affiliated with or endorsed by FUTO. Always confirm scope with the current lecturer.

## How to use a guide

1. Read the **Course Content Summary** table. It ranks each concept by importance and how often it has been examined.
2. Take one topic at a time. The **Study** line names the exact pages; the **Exam** line names the past-paper questions that topic lets you answer.
3. Read only those pages, work two or three examples, then attempt the named questions with the book closed.
4. Tick a checkbox only when you can explain the idea and reproduce the calculation without notes.

Each guide ends with a **Refresh** line (the prerequisite bits worth revising) and a **Priority** line for the final week.

## How the guides were built

The evidence hierarchy is BMAS synopsis → course notes and textbooks → past papers → external references. "Exam likelihood" is a count across the papers that were available for that course (two or three, sometimes one), not a prediction. The method, and its limits, are documented in [`docs/methodology.md`](docs/methodology.md); the paper list and question-numbering convention are in [`docs/past-papers.md`](docs/past-papers.md).
