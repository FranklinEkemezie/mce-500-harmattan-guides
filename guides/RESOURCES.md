# Course materials — not redistributed

This repository contains only the study guides. The textbooks, lecture notes, past papers and scanned handouts are **not** committed, for copyright and privacy reasons.

They live in the shared Drive folder used by the department/cohort:

**https://drive.google.com/drive/folders/1AMXxyOkdVCyCGpy0DHT8tW7dCgvBISQ7**

If that link stops working, ask a course mate or the class representative for the current folder.

## Why the PDFs are excluded

- Most of the textbooks are commercial works (Pearson, Wiley, Springer, Elsevier, MIT Press).
- The lecturer notes and past papers belong to the department and the individual lecturers.
- Some files carry personal annotations or watermarks.
- Git stores binary files forever; a 270 MB folder would make the repository painful to clone.

The guides cite chapter, section and page numbers instead, so the repository stays small and the sources stay where they belong.

## What is safe to add

- A correction to a page number or a better open-access reference.
- A link to a legally free version (author's preprint, MIT OCW, publisher's sample chapter).
- Your own worked solution to a past question, written in your own words — not a scan or transcript of the paper.

Do **not** open a pull request that adds a PDF, a scan, a DOCX, or a copied passage from a textbook.
