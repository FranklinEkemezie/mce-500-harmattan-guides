# Guides — 500 Level Harmattan

One file per course. Every guide has the same shape: overview, BMAS synopsis, sources, a topic/importance/exam-likelihood table, then topic-by-topic **Study → Exam → checklist** blocks. They are deliberately compact: roughly 10–16k characters each (4–6 printed pages), not a textbook.

## How to use

1. Read the **Course Content Summary** table first. It tells you where the marks are.
2. Work one topic at a time:
   - **Study** names the exact chapter, section and page range. Read only that.
   - **Exam** names the past-paper questions that topic unlocks. Attempt them with the book closed.
   - Tick a checkbox only when you can explain the idea and do the calculation without notes.
3. Use the **Exam likelihood** column to decide depth: "Very high" means drill the past-paper calculations; "Low/Unknown" means one page plus one example.
4. Each guide ends with a **Refresh** line for prerequisites and a **Priority** line for the last week.

## Reference policy

What is not in this repository, and why: [RESOURCES.md](RESOURCES.md).

- Textbook references are chapter/section/page specific, taken from the PDFs in the course Drive folder (see the root README). Page numbers refer to those PDFs; other editions may shift by a few pages.
- Where a course has no adequate text, the guide points to a free, verified source: MIT OpenCourseWare (6.003, 2.003SC, 6.777J), the Modern Robotics site, `dspguide.com`, RealPars, or Purdue OWL for IEEE style.
- Online links are optional backup; the book chapter is always the primary source.
- Prerequisites are named but not referenced, on the assumption that a 500-level engineering student can revise them from their own notes.

## Evidence notes

- **Past papers used:** Harmattan 2019/2020, 2020/2021 and 2021/2022 (plus the MCE 523 2019 paper). Frequencies in the tables are counts out of the papers available for that course — a small sample, not a syllabus boundary.
- **Taught material:** lecturer notes and textbooks from the course Drive folder. Several lecturer notes are handwritten scans; where that matters, the guide says so.
- **Excluded:** MCE 505 (Microcomputers), MCE 509 (Control Engineering II) and MCE 527 (Cyber Security) have resources in the Drive folder but are **not** on the 500-level Harmattan course list, so no guides were written for them.
- **MCE 511 code:** the handwritten list is ambiguous between 505 and 511; the resource folder and Drive both say **MCE 511 — Process Automation Management**, which is used here.
- **MCE 515 and 529** have no BMAS entry; their guides follow the closest BMAS analogues (MCT 599/MCT 413) and standard FUTO practice, and say so explicitly. Their "Exam" lines name deliverables rather than past questions.
- **MCE 521** has no supplied notes or past paper; its content is reconstructed from BMAS MCT 519, MIT 6.777J and standard texts, and is labelled as inference.
- **MCE 507** has only one readable past paper (2020/2021); the 2023 paper exists only as images.
